# Course dataset

`build_epl_shots.py` builds shot-level EPL datasets from StatsBomb open data in
the style of the course's NBA, WNBA and NHL datasets: Premier League 2015/16
(all 380 matches) and 2003/04 (the 38 Arsenal matches in the open data). Each
row is a shot with the players on the pitch for both sides.
`epl_codebook_entry.docx` is its entry for the course codebook.

```
python3 build_epl_shots.py
```
