# StatsBomb 2015/16 pipeline: shot volume, shot quality, and big chances

Soccer analytics project on StatsBomb open data for four leagues (Premier League, La Liga, Serie A, Ligue 1, 2015/16).

- Stage 1: team-match data; shot volume and shot quality modeled separately; big chances defined.
- Stage 2: stints and segments (stretches of play with the same players), and whether that data can separate individual players.
- Stage 3: player models for shot volume, compared out of sample against a team-only model.
- Stage 3b: the same models on segments (exact score, time remaining controlled), plus a positional prior.

## How it runs

The whole analysis is one `targets` pipeline. From the project root:

``` r
targets::tar_make()          # run everything that is out of date
targets::tar_visnetwork()    # see every step and what depends on what
targets::tar_read(cv3)       # pull any result into your session
targets::tar_outdated()      # what would rerun, without running it
```

Each step is cached and reruns only when its inputs or the functions it uses change: editing a plot reruns only that report; editing the cross-validation code reruns only cross-validation and what depends on it. Independent steps (the 10 cross-validation folds, the jackknife fits) run in parallel when the `crew` package is installed. There is no run order to remember and no hand-off `.rds` files: the cache in `_targets/` replaces them.

The reports in `reports/` only read results; they never fit anything. The pipeline renders them, and once it has run you can also knit any report by hand.

One warning is expected: Ligue 1 has 377 of 380 matches in the open data, and the warning is kept so the gap is never silent.

## Setup

1.  Install packages: `install.packages(c("targets", "tarchetypes", "crew", "mcglm", "Matrix", "MASS", "mixtools", "glmnet", "dplyr", "readr", "tibble", "ggplot2", "rmarkdown", "knitr", "testthat"))` (`crew` is optional; without it everything runs in one R session.)
2.  Python 3 with `requests` (`pip install requests`). The pipeline uses the `PYTHON` environment variable if set, otherwise `python3`. If RStudio finds a different Python than your terminal, add `PYTHON=/full/path/to/python3` to `~/.Renviron` and restart R.
3.  Run the tests: `testthat::test_file("tests/test_pipeline.R")`.
4.  Run the pipeline: `targets::tar_make()`.

The first run does everything once (the build itself is quick when the download cache exists); later runs only redo what changed. Parallel workers default to up to 4; set `SB_WORKERS=1` in `~/.Renviron` to turn them off.

## Decisions and the evidence behind them

**Data source: StatsBomb, with Understat as a reference.** The team-interaction work needs who was on the pitch for every shot, which only StatsBomb provides. The Understat results appear as a reference column in the summary table. On the EPL 2015/16 season both sources cover, they agree on shot counts (team-match correlation 0.991) and broadly on xG (0.896).

**Leagues: Premier League, La Liga, Serie A, Ligue 1, 2015/16.** These are the complete seasons in the open data. The 2015/16 Bundesliga (34 matches) and EPL 2003/04 (Arsenal only) are partial and excluded.

**Open-play shots only.** StatsBomb's xG is calibrated for open-play shots (goals / xG = 1.03) but underrates direct free kicks (113 goals vs 69.5 expected, ratio 1.63) and direct shots from corners. Penalties were already excluded in the Understat work. Excluding direct set pieces removes 4.7% of shots and makes totals about 3% lower than Understat's npxG by construction. Evidence: `reports/1_team_models.Rmd`, section 2.

**Team-match table built from the matches table**, so team-matches with zero shots are kept for the volume model.

**League effect instead of season effect; team effects sum to zero within each league.** With one season, team and team-season are the same.

**Tweedie kept as a benchmark.** Its index p is the test that motivates modelling volume and quality separately: if team xG were a single compound Poisson-gamma, five independent estimates of p would agree. They don't fully (the shot shape implies p of about 1.64 against a fitted 1.49), though the gap is smaller here than on Understat (about 2 SEs vs about 6). Evidence: `reports/1_team_models.Rmd`, section 5.

**Volume: negative binomial.** Mild overdispersion, nearly identical to Understat (residual deviance per df of 1.08 in both).

**Quality: a three-component lognormal mixture on shot xG, fit once on pooled data.** Shot xG is not gamma-distributed in either source (the moment and MLE shape estimates differ by nearly a factor of 2). The mixture has a long-range cluster (about 4% of shots at median xG 0.007, from about 34 yards), a core (about 85%), and a high-value tail (about 11% at median 0.31, from about 9 yards, mostly first-time, converting about 42%). Understat's sharp two-peak shape does not appear in StatsBomb; what replicates is the high-value tail. The fit uses an informed start plus random starts and reports how many agree. The structure reproduces in every league, but in half the data two 3-component solutions can tie in likelihood, so the mixture is never refit on subsets such as single teams. Evidence: `reports/1_team_models.Rmd`, section 6.

**Big chance = posterior probability of the top mixture component** (`p_top` in the saved shots). Probabilities rather than hard labels keep borderline shots counted correctly in team-level shares.

**Prediction: the two-part model (NB volume x Gamma quality) matches the Tweedie exactly** (r = 0.534 for both) and is well calibrated at both tails. Evidence: `reports/1_team_models.Rmd`, section 7.

## Stage 2 decisions

**Stints end at a substitution, a red card, or the end of a half.** Times come from event timestamps within each period, so stoppage time is included. Zero-length stints (halftime substitutions recorded at 0:00 of the second half) are dropped. The build stops if any shot falls outside a stint, if stints leave gaps within a half, or if a side has fewer than 7 or more than 11 players.

**Temporary absences are ignored.** A player off briefly for treatment counts as on the pitch; tracking these would create many tiny stints.

**Exposure counts all playing time, but only open-play shots are counted**, matching stage 1. Teams that win many set pieces get slightly lower rates; the bias is small and consistent.

**Short stints are kept.** Minutes are used as exposure, which weights them appropriately.

**The open-play filter and big-chance probabilities stay in R.** The build only labels each shot with its stint; stint totals are computed from stage 1's shots, and the stint table must reproduce the stage 1 team-match table exactly.

**Identification diagnostics use the shot-volume model.** Volume, xG, and big chances share the same design matrix, so the collinearity is identical across them; only the scale differs. Standard errors come from the Fisher information of a Poisson model at the league-average shot rate.

**One effect per player across teams.** Mid-season transfers help identification by breaking up a player's co-occurrence with one set of teammates.

**Players below 900 minutes are pooled** into a per-league replacement level, with sensitivity checks at 300 and 1,800 minutes.

**Goalkeepers get defensive effects but no offensive ones.** A starting goalkeeper plays nearly every minute, so his effect is almost inseparable from the team's level. Positions come from StatsBomb lineups (primary position = most frequent across matches).

**Aliased columns in the identification diagnostics are ever-present players.** The two aliased defense columns (Kasper Schmeichel, Leicester; Dennis Appiah, Caen) belong to teams with an ever-present goalkeeper and an ever-present defender: their defense indicators are identical. Ridge splits the effect between them, and the team-plus-players model treats them as deviations from their team.

## Stage 3 decisions

**Models.** M0: league, home, and game state. M1: M0 plus team attack and defense effects. M2: M0 plus player offense and defense effects. M3: M1 plus player effects as deviations from team. Player effects are ridge-penalized; everything else is unpenalized.

**Game-state controls** (score difference capped at plus or minus 2, and player counts) are included because substitutions depend on the game state.

**Likelihood chosen by a check, not assumed.** M1 is fit as a Poisson model on the stints; if its Pearson dispersion is 1.1 or more, a negative binomial with theta fixed at its maximum-likelihood value is used instead. At the stint level expected counts are about one shot, so the negative binomial's extra variance (mu / theta, about 3% with stage 1's theta) is expected to be small.

**Penalty maps to a prior SD.** glmnet is run with standardize = FALSE and the penalty scaled so it equals a N(0, tau\^2) prior on each player effect (log scale); a unit test checks this against the posterior mode computed directly. tau is chosen by held-out deviance over 10 folds of whole matches.

**The key tests are out-of-sample improvement over M1 and split-half reliability** (M3 fit separately on alternating matches; player effects correlated for players with 300+ minutes in each half). Individual rankings are only interpreted if reliability is meaningfully above zero.

**xG and big chances come later**, with the same design. xG is continuous, so it will use a Tweedie likelihood with p near the stage 1 estimate.

## Stage 3b decisions

**Segments fix a flaw in the stint table.** Stints split only at substitutions and red cards, so the score recorded at a stint's start was stale after any goal within it. Segments also split at goals (a goal's shot stays in the segment before it) and at 15-minute game-clock edges within each period (stoppage time falls in the last bin). Segments sum exactly to stints, and segment totals must reproduce the stage 1 team-match table.

**Game state = score difference x time bin** (5 x 6 cells, unpenalized), because a deficit late in a match produces far more shooting than one early on.

**Why time controls matter for positions.** Every lineup has roughly the same mix of positions, so position effects are identified mainly when substitutions change the mix, and substitutions happen late and in specific game states. Position effects are compared with and without time controls: if they shrink substantially, they were mostly substitution timing.

**M4: positional prior.** Counts of attacking players in CB / FB / FW and defending players in GK / CB / FB / FW (midfield the reference) enter unpenalized, so each player's ridge effect is a deviation from his position's mean. Groups come from primary positions; "Unknown" positions are not counted. Position effects get delete-one-fold jackknife SEs; both control settings use M4's chosen prior SD.
