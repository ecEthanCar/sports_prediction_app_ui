Stage 3b: Time Controls and a Positional Prior

Results come from the pipeline (targets::tar_make() in the project root); this report only reads and displays them. The models run on segments (exact score), with game state as score difference x six 15-minute bins. M4 adds counts of each position group on the pitch, unpenalized, so each player’s effect is a deviation from his position’s mean.

One more player of the group in place of a midfielder, % shots per 90, with delete-one-fold jackknife SEs. Offense: positive means more shots taken. Defense: positive means more shots conceded.
